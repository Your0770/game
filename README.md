# FPS Game Planning Example

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **  미로탈출  ** |
| 장르 | Escape, Puzzle |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | third Person |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개
> 안개로 덮인 미로 속에서 여러가지 퍼즐을 풀어 탈출하는 게임.

---

## 2. 게임 컨셉

플레이어는 안개가 가득 덮인 미로에서 깨어난다.

미로에는 여러가지 문서와 퍼즐이 존재하며, 플레이어는 문서를 이용하여 퍼즐을 풀어 탈출에 필요한 힌트를 얻는다.

최종적으로 모든 퍼즐을 풀어, 출구를 찾아 탈출하여 게임을 클리어한다.

### 핵심 키워드

- **Explore** : 미로 탐색
- **Collect** : 문서 획득
- **Escape** : 탈출구 개방 및 게임 클리어

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 미로 내부를 탐색한다.
2. 미로에 숨겨진 문서를 획득한다.
3. 미로에 숨겨진 기믹을 수행한다.
4. 탈출구까지 이동한다.
5. 탈출하면 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
문서 획득
  ↓
탐색
  ↓
기믹 수행
  ↓
다음 기믹에 대한 힌트 획득
  ↓
탈출
```

플레이어는 게임이 종료될 때까지 **탐색 → 아이템 획득 → 이동 -> 상호작용**의 과정을 반복한다.

---

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Space | 점프 |
| Shift | 달리기 |
| F | 아이템 획득 / 상호작용 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 FPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기
